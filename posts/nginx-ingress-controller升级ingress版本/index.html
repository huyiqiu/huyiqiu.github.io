nginx-ingress-controller升级ingress版本

星期一, 1月 6, 2025 | 6分钟阅读 | 更新于 星期一, 1月 6, 2025

@ Eqiu

升级nginx-ingress-controller中nginx的版本

1. 背景

我们使用rancher自带的nginx-ingress-controller作为k8s集群的负载均衡器，但是由于rancher的版本较老，nginx-ingress-controller 中的nginx版本也较老，不符合安全扫描的要求，因此我们需要升级nginx-ingress-controller中nginx的版本。

注意

  1. 我们不升级nginx-ingress-controller的版本，因为其与K8s的版本绑定
  2. 我们不使用其他ingress-controller，因为需要使用rancher界面来设置负载均衡

2. 操作方法

  • 克隆源码
1
2
3

git clone https://github.com/rancher/ingress-nginx.git && cd ingress-nginx
# 进入你使用的controller版本分支，这里我使用的是nginx-0.35.0-rancher2
git checkout nginx-0.35.0-rancher2
  • 进入Nginx构建目录
1

cd images/nginx/rootfs
  • 修改构建脚本
1

vi build.sh
  • 构建Nginx镜像
1

docker build -t nginx-base-image:v0.1 .
  • 根据编译的报错信息，修改报错模块的版本，直到编译成功
  • 修改ingress-nginx的基础镜像
1
2
3

cd ../../../
vi Makefile
# 将BASE_IMAGE修改为重新构建的nginx镜像
  • 构建ingress-nginx-controller镜像
1

make image ARCH=amd64
